# 图志美术系统

本轮将田野、港湾、山谷、庭园的视觉方向落在 FC01、FC16、FC23、FC32 四张样板页。其他关卡保留原有地标，同时共用新的纸张、边界、颜料和章节页样式。

## 实现

- `src/render/scenery.js` 集中管理手绘 SVG 路径、插画布局和章节扉页。田野使用村舍与风车，港湾使用帆船与灯塔，山谷使用山峰与桥梁，庭园使用亭子与喷泉。
- 样板插画放在已验证的区域内切圆中，避开固定印章及目标区域。FC23 的另一种地图布局也按自己的安全位置布置插画。
- 解题时隐藏插画；完成后逐步显现。收藏重绘始终显示插画，缩略图、全图和 PNG 导出共用同一组路径。
- 外轮廓加重、内部边界减细，所有线段来自原有编译结果，不修改区域形状、邻接关系或关卡校验值。
- 桌面与纸张分层，纸纹和颜料纹理降低对比；高对比皮肤保留更清晰的纹理与边界。四枚颜料调整为轻微不规则的压印形状。
- 四章加入插画扉页，完成卡片加入细线标记；减少动态效果设置继续生效。

## 验证

`npm run verify`：68 项规则/内容检查、30 项浏览器场景通过。新增测试验证所有主线、短篇及替代视图的边界分层无遗漏、无重复，四张样板插画不越界且避开印章与目标。浏览器直接测量实际 SVG 路径包围盒及描边，验证共享安全包络，并覆盖完成、撤销/重做、收藏与翻面时的插画显隐。

手工检查四张样板的解题/完成状态、章节页，以及窄屏暗色和桌面布局。截图环境缺少中文字库，因此视觉检查使用英文，浏览器功能测试继续覆盖中文。

`node tools/checks/budget.mjs`：首屏 JavaScript gzip 53.7 KB，低于 150 KB 预算。未引入位图下载或新依赖。
